4. Layers in a Neural Network

Input → Hidden → Output — what actually happens at each
Counting layers: Input layer is NOT counted. A "2-layer network" = 1 hidden + 1 output. Input is just the data entry point — no weights, no computation.

5. Why Multiple Hidden Layers?

Each layer learns a more complex concept than the previous
Why "Deep"? Deep = many hidden layers. One wide layer could theoretically learn anything but needs millions of neurons. Multiple layers are efficient — each only learns a small step beyond the previous.

6. How Training Works

Full training loop — 5 steps, repeated thousands of times
Dataset is used every step! The model always compares against real labels from your data. It never learns from its own outputs alone — the label is the "teacher".

Output size = (n - f + 1) × (n - f + 1)

10. Why Convolution? Important vs Unwanted Pixels

Key insight: In any image, most pixels are background noise — sky, wall, floor, irrelevant surroundings. The network only needs the informative pixels — facial features, object outlines, textures. Convolution is the mechanism that captures these important pixels and discards irrelevant ones.
Raw image has millions of pixels — most are noise. Convolution extracts only the meaningful signal.

Why convolution is perfect for this

  • Background pixels (uniform sky, plain wall) have low variation → filter produces low/zero activation → suppressed automatically
  • Edge pixels (where colour changes sharply — face outline, eye boundary) cause high filter activation → captured strongly
  • Texture pixels (skin, fur, hair pattern) → specific filters activate → captured
  • After convolution + pooling: background noise → nearly 0. Important features → HIGH values. The noise is filtered out, the signal is kept.
This is also why CNNs need less data than FNNs. An FNN has to memorise "the koala is always in the centre-left of the image." A CNN learns "there's a round nose shape" — it finds that shape wherever it appears in the image, because the filter slides everywhere. Position doesn't matter.

11. Feature Vectors — The Core Insight

Same filters, different images → different number sequences → ANN identifies the class
This concept — feature vector / embedding — is everywhere in modern AI: face recognition (same person = similar vectors), Spotify recommendations (similar songs = similar vectors), Google image search, ChatGPT understanding language (similar meaning = similar vectors).

14. Interview Quick Answers

Q: Why do we need activation functions?
Without them, stacking layers collapses to one linear equation — no matter how deep, the model can only draw a straight line. Activation functions add non-linearity so the network can learn complex, real-world patterns.
Q: Difference between parameters and hyperparameters?
Parameters (weights, biases, kernel values) are learned automatically by backpropagation during training. Hyperparameters (learning rate, filter size, number of layers, batch size) are set by the engineer before training and stay fixed. Hyperparameter tuning is done manually or with Grid/Random Search.
Q: Why CNN over FNN for images?
FNN needs one neuron per pixel — a 1920×1080 image needs 6.2M input neurons, each connected to every hidden neuron — billions of weights. CNN uses small filters (just 9 weights for 3×3) reused across the entire image (parameter sharing) — massively efficient. Also, CNN understands spatial structure — nearby pixels matter. FNN treats all pixels independently.
Q: Do filters in a CNN change per class — like "cat filters" vs "dog filters"?
No. One shared set of filters is used for ALL images always. Filters detect low-level visual features — edges, curves, textures. The same "edge detector" fires on a cat's ear and a dog's ear. The FC layer at the end learns which combination of filter activations corresponds to which class.
Q: What is a feature vector / embedding?
After flattening the CNN output, each image becomes a list of numbers — its mathematical fingerprint. Similar images produce similar vectors. The FC layer learned during training which vector patterns map to which class. Same concept powers face recognition, Spotify recommendations, and language understanding in LLMs.
Q: What is backpropagation?
After computing the loss, the error signal travels backward through ALL layers simultaneously using the chain rule (calculus). Each weight is told how much it contributed to the error. Gradient descent then nudges all weights slightly in the direction that reduces the loss.
Q: What does pooling do and why?
Pooling (max pooling most common) shrinks the feature maps by taking the max value in each small region (e.g. 2×2). This reduces computation, makes the network position-independent (feature detected anywhere in that region), and reduces overfitting by removing some noise.
Q: Why do images have "unwanted" pixels and how does CNN handle them?
In a real image, most pixels are background — sky, walls, floors — that carry no information about the object. Convolution filters produce high activations only where important patterns (edges, textures, shapes) exist, and near-zero activations on flat/uniform background regions. Pooling further suppresses weak activations. So by the time the image reaches the FC layer, most of the noise is gone and only the meaningful signal remains.
